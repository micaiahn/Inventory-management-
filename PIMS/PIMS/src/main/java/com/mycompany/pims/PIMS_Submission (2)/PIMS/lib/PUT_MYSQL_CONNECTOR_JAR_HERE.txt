Put the MySQL Connector/J jar here before opening this project in NetBeans.

1. Download the "Platform Independent" ZIP from:
   https://dev.mysql.com/downloads/connector/j/
2. Extract it and copy the .jar file (e.g. mysql-connector-j-9.1.0.jar)
   into this /lib folder.
3. Rename it to exactly:  mysql-connector-j.jar
   (or, if you'd rather keep the version number in the filename, open
   nbproject/project.properties and change the
   file.reference.mysql-connector-j.jar line to match your filename.)

Once the jar is here, NetBeans will resolve the project's library
reference automatically when you open it - no extra "Add JAR" step
needed.
